# 🌐 Digital Metrik
Mesin simbolik untuk DM🌐NFT—di mana metrik menjadi mitos. Setiap aset adalah simpul dalam orbit identitas, berdenyut dengan data, cerita, dan transformasi.

## Metrik Inti
- 🌀 Kehadiran: Seberapa sering aset dilihat/digunakan
- 🔁 Gaung: Jumlah share, remix, repost
- 🧬 Resonansi: Dampak emosional (feedback, reaksi)
- ⏳ Peluruhan: Waktu sejak interaksi terakhir
- ♻️ Reinkarnasi: Re-minting, rebranding, atau evolusi lore

## Teknologi
- Metadata ERC-1155
- Animasi titik orbit (CSS/JS)
- Pemicu ARCore (opsional)
- GitHub sebagai arsip hidup
